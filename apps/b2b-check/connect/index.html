Connect MDB B2B Check

Server address (MCP, Streamable HTTP, no sign-in):

https://b2b.mdb-group.info/mcp

Claude (claude.ai and desktop app)

  1. Open Customize → Connectors.
  2. Select + and then Add custom connector.
  3. Name: MDB B2B Check. URL: the address above. No sign-in is needed.
  4. In a chat, ask for example: “Is SK2120577756 a valid VAT ID?”

Custom connectors need a paid Claude plan. Once the app is listed in the Claude directory, you can add it from there instead.

ChatGPT and other assistants

Any assistant that supports remote MCP servers can use the address above without sign-in. In ChatGPT, use the app from the app directory once it is listed there.

The app is listed in the official MCP Registry as info.mdb-group/b2b-check.

Your own programs

The same checks over HTTP: POST https://b2b.mdb-group.info/api/v1/<tool> with the arguments as a JSON body. Described in openapi.json and llms.txt. Without sign-in, each connection can run 30 checks in 10 minutes.

In the browser

Without an assistant: b2b.mdb-group.info checks up to 10 numbers at once and offers a full partner check.

MDB B2B Check verbinden

Adresse des Servers (MCP, Streamable HTTP, ohne Anmeldung):

https://b2b.mdb-group.info/mcp

Claude (claude.ai und Desktop-App)

  1. Customize → Connectors öffnen.
  2. + und dann Add custom connector wählen.
  3. Name: MDB B2B Check. URL: die Adresse oben. Eine Anmeldung ist nicht nötig.
  4. Im Chat zum Beispiel fragen: «Ist SK2120577756 eine gültige USt-IdNr.?»

Eigene Connectors brauchen einen bezahlten Claude-Plan. Sobald die App im Claude-Verzeichnis steht, können Sie sie stattdessen von dort hinzufügen.

ChatGPT und andere Assistenten

Jeder Assistent mit Unterstützung für entfernte MCP-Server kann die Adresse oben ohne Anmeldung nutzen. In ChatGPT nutzen Sie die App aus dem App-Verzeichnis, sobald sie dort steht.

Die App steht in der offiziellen MCP Registry als info.mdb-group/b2b-check.

Eigene Programme

Dieselben Prüfungen über HTTP: POST https://b2b.mdb-group.info/api/v1/<tool> mit den Argumenten als JSON. Beschrieben in openapi.json und llms.txt. Ohne Anmeldung sind pro Verbindung 30 Prüfungen in 10 Minuten möglich.

Im Browser

Ohne Assistent: b2b.mdb-group.info prüft bis zu 10 Nummern auf einmal und bietet einen ganzen Partner-Check.
